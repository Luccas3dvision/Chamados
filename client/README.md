# Cliente Vue

Interface Vue 3 + Vite para o sistema de chamados. Consulte o
[README principal](../README.md) para a visão geral, instalação, contas locais e
instruções para iniciar cliente e API.

## Comandos

```powershell
npm ci
npm run dev
```

Para validar a versão de produção:

```powershell
npm run build
```

O cliente usa `http://127.0.0.1:8000/api` por padrão. Configure `VITE_API_URL`
para apontar para outra API.
